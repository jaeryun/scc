# decisions/ — 아키텍처 결정 기록

프로젝트 전반에 영향을 주는 아키텍처 결정을 시간 순으로 기록합니다.

## 작성 규칙

- 파일명: `adr-NNN-<kebab-case-title>.md`
- 각 ADR은 결정의 배경, 고려한 대안, 결정 사항, 결과를 포함
- 뷰별 결정은 `views/<view>/decisions/`에 별도 기록 가능

현재는 스캐폴드 — 결정이 내려짐에 따라 콘텐츠가 추가됩니다.
