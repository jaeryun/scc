# CLAUDE.md 작성 규칙

## 프로젝트 루트 CLAUDE.md

프로젝트 내 모든 활동에서 항상 로딩되는 최상위 지침. 실제 지침은 `docs/common/foundation/` 개별 문서에 작성하고 여기서는 `@`로 포함만 한다.

- [필수] `@docs/common/foundation/` 내 모든 문서를 `@`로 포함
- [금지] 이 파일에 실제 지침을 직접 작성하지 않는다

## 하위 디렉터리 내 CLAUDE.md

해당 디렉터리 작업 시 자동 로딩되는 AI 지침. 필요한 지침만 동적으로 로딩할 수 있게 분리한다.

- [필수] 문서 제목 바로 아래 `@index.md`를 기입 — 디렉터리/파일 구조는 index.md의 역할
- [필수] 현재 디렉터리의 내용만 다룬다 — 상위/하위 디렉터리 내용은 해당 디렉터리의 CLAUDE.md에 위임
- [권장] 중복 방지를 위해 가급적 `docs/` 하위에 세부 지침을 문서화하고 `@`로 링크
- [권장] `@` 링크 위주로 간결하게 작성

## 템플릿

```markdown
# <디렉토리명>/ — <한 줄 목적>

@index.md

<1-2문장 설명. 이 디렉토리가 무엇을 담고, 어떤 역할을 하는지>.

**로딩 시점:** <조건>

## 규칙

### 추가해도 되는 것

- <항목>

### 추가하면 안 되는 것

- <항목> → `<올바른 위치>`
```
