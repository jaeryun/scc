# index.md 작성 규칙

사람과 AI가 함께 보는 디렉터리 구조 문서.

## 작성 규칙

- [금지] **AI 지침 작성 금지** — 로딩 시점, 행동 규칙 등은 CLAUDE.md의 역할
- [금지] **`@` 참조 사용 금지** — 일반 마크다운 링크 `[link](path)`만 사용

## 템플릿

```markdown
# <디렉토리명>/ — 구조와 파일 목록

## 디렉터리 용도

<디렉터리 용도와 목적>

## 디렉터리 구조

| 디렉토리/파일 | 용도 | 키워드 |
|----------|------|---------|
| `<디렉터리명>/` | <용도> | <키워드 , 로 구분> |
| `<파일명>` | <용도> | <키워드 , 로 구분> |

## 포함 금지 항목

- <금지항목1>
- <금지항목2>
```
