# index.md 작성 규칙

사람과 AI가 함께 보는 디렉터리 구조 문서.

## 작성 규칙

- [금지] **AI 로딩 지시 작성 금지** — 언제 읽고 언제 읽지 말라는 식의 순수 AI 대상 지침은 CLAUDE.md의 역할. 문서 배치 규칙, 디렉터리 경계 기준, 구조 컨벤션 등 사람도 알아야 할 규약은 index.md에 작성 가능
- [금지] **`@` 참조 사용 금지** — 일반 마크다운 링크 `[link](path)`만 사용

## 템플릿

```markdown
# <디렉토리명>/ — 구조와 파일 목록

## 디렉터리 용도

<디렉터리 용도와 목적>

## 디렉터리 구조

| 디렉토리/파일 | 용도 | 키워드 |
|----------|------|---------|
| `<디렉터리명>/` | <용도> | <키워드 , 로 구분> |
| `<파일명>` | <용도> | <키워드 , 로 구분> |

## 포함 금지 항목

- <금지항목2>
```
