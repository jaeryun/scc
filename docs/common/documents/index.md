# documents/ — 구조와 파일 목록

## 디렉터리 용도

파일 유형별 문서 작성 규칙과 템플릿.

## 디렉터리 구조

| 디렉토리/파일 | 용도 | 키워드 |
|----------|------|---------|
| `documents/` | 문서 작성 규칙 모음 | 문서화, 규칙, 템플릿 |
| `general.md` | 공통 규칙 + 일반 문서 규칙 | 언어, 참조금지, kebab-case |
| `claude-md.md` | CLAUDE.md 작성 규칙 + 템플릿 | CLAUDE.md, AI 지침, 템플릿 |
| `index-md.md` | index.md 작성 규칙 + 템플릿 | index.md, 디렉터리 구조, 표 |
| `readme-md.md` | README.md 작성 규칙 | README.md, 금지 |
| `rules-md.md` | .claude/rules/ 파일 작성 규칙 + 템플릿 | rules, 프록시, 프론트매터 |
| `index.md` | 이 파일 — documents/ 디렉터리 구조 | 인덱스 |
| `CLAUDE.md` | AI 에이전트 로딩 지침 | AI, 로딩 |
