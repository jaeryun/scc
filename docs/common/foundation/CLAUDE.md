# foundation/ — 프로젝트 헌장

SCC 프로젝트의 정체성, 제약, 아키텍처, 행동 원칙을 정의합니다.
**이 디렉토리는 항상 컨텍스트에 로딩됩니다** (루트 CLAUDE.md에서 `@docs/common/foundation/*` 참조).

- `project.md` — 프로젝트 개요, 기술 스택, 제약사항, 빌드 명령, 디렉토리 구조
- `architecture.md` — 모듈 기반 구조, 뷰 시스템, 데모/제품 경계, 컴포넌트 배치
- `behavior.md` — AI 행동 원칙 (구현 전/중/후, 목표 주도 실행, CLAUDE.md 현행화)
- `conventions.md` — 핵심 코딩 규칙 (cn(), 아이콘, tsc/build) + development/ 규칙への 포인터

> 구조와 파일 목록은 `@docs/common/foundation/index.md` 참조.
