# common/ -- 모든 뷰의 공통 기반

이 디렉토리는 특정 뷰에 귀속되지 않고 프로젝트 전체가 공유하는 문서를 담습니다.

## 구조

| 디렉토리 | 목적 | 로딩 시점 |
|----------|------|-----------|
| `foundation/` | 프로젝트 헌장 -- 정체성, 제약, 핵심 결정사항 | 항상 |
| `rules/` | 코딩 규칙 -- SCC 고유 결정사항 | 위반 시 |
| `dev-patterns/` | 개발 패턴 -- 코드 예제, 구현 방법 | 구현 중 |
| `operation/` | 운영 가이드 -- 빌드, 배포, 장애 대응 | 운영 시 |
| `reference/` | 참조 자료 -- API 문서, 데이터 모델, env 변수 | 필요 시 |
| `adr/` | 아키텍처 결정 기록 | 결정 검토 시 |
